
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Pratique manipulação de strings, loops, condicionais e seleção aleatória em Python, criando um jogo em que o jogador tenta adivinhar uma palavra oculta antes de esgotar as tentativas.

## 📝 Tarefas

### 🛠️ Seleção da Palavra e Registro de Palpites

#### Descrição

Selecione uma palavra aleatoriamente de uma lista predefinida e permita que o jogador tente adivinhá-la, exibindo o progresso após cada palpite.

#### Requisitos

O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras fornecidos pelo jogador.
- Mostrar as letras adivinhadas nas posições corretas e indicar as letras ainda não descobertas, por exemplo, `_ _ _`.
- Atualizar o estado do jogo quando o palpite estiver correto ou incorreto.

### 🛠️ Controle de Tentativas e Fim do Jogo

#### Descrição

Controle as tentativas incorretas e encerre a partida quando o jogador adivinhar a palavra ou não tiver mais tentativas disponíveis.

#### Requisitos

O programa concluído deve:

- Rastrear e exibir o número de tentativas incorretas restantes.
- Encerrar o jogo quando todas as letras da palavra forem adivinhadas ou as tentativas se esgotarem.
- Exibir uma mensagem de vitória quando o jogador adivinhar a palavra.
- Exibir uma mensagem de derrota e revelar a palavra quando as tentativas se esgotarem.
